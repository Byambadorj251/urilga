# Нэг жижигхэн бэлэг

Монгол хэл дээрх утсанд эвтэйхэн болзооны урилга. Хариуг сервер талын Resend API-аар `byambadorj023@gmail.com` рүү явуулна. API түлхүүр тохируулаагүй бол сайт амжилттай болсон мэт харуулахгүй.

## Орон нутагт ажиллуулах

Node.js 20 эсвэл түүнээс шинэ хувилбар шаардлагатай. PowerShell-ийн төслийн хавтаснаас:

```powershell
npm.cmd install
npm.cmd start
```

`http://localhost:3000` хаягийг нээнэ. `public/index.html`-ийг шууд нээх эсвэл зөвхөн статик Live Server ашиглавал email backend ажиллахгүй.

## Интернетэд байрлуулж хуваалцах

Төслийн үндсэн хавтсанд байгаа `render.yaml` Render Web Service-ийн тохиргоог бэлдсэн. Байрлуулахын тулд:

1. Төслийг GitHub repository-д оруул. `.env` нь `.gitignore`-т байгаа тул API түлхүүр repository-д орохгүй.
2. [Render](https://render.com)-т бүртгүүлж GitHub-аа холбоод **New → Blueprint** сонгон repository-гоо сонго.
3. `RESEND_API_KEY` асуух үед Resend dashboard-оос **шинэ API key** үүсгээд Render-д оруул. `RECIPIENT_EMAIL` аль хэдийн `byambadorj023@gmail.com` байна.
4. Deploy дуусахад Render `https://...onrender.com` URL өгнө. Тэр холбоосыг нөгөө хүнд явуул.

Free web service нь 15 минут хүсэлтгүй байвал унтаж, дараагийн хүсэлтээр ойролцоогоор нэг минутын дотор сэргэдэг. Холбоос нь хэвээр, гэхдээ эхний нээлт удааширч болно. Тасралтгүй ассан байх шаардлагатай бол Render-ийн төлбөртэй plan сонго.

`.env` болон API түлхүүрийг browser кодод бүү оруул. Email зөвхөн Resend сервер хүсэлтийг амжилттай хүлээн авсны дараа амжилттай гэж харагдана.
